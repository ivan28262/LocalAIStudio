Возможности

Всё необходимое для локального ИИ — в одном месте.

Приложение объединяет каталог моделей, загрузку, управление и чат в одном интерфейсе.

🤖

Локальный запуск

Модели работают непосредственно на компьютере пользователя через внутренний Ollama runtime.

📦

Каталог моделей

Семейства Qwen, Llama, Gemma, Mistral, DeepSeek, Phi, Granite и другие.

📥

Загрузка моделей

Размер, параметры, назначение, русский язык и требования отображаются прямо в каталоге.

💬

Чат

История, потоковая генерация, Markdown и индикатор «Модель думает…».

📎

Файлы

Поддерживаемые текстовые документы можно прикреплять к запросу через кнопку «+».

🖼️

Изображения

Vision-ввод доступен для совместимых мультимодальных моделей, например LLaVA.

🌐

Интернет-поиск

Дополнительный режим через Ollama Web Search передаёт найденные материалы локальной модели.

📚

История чатов

Чаты хранятся локально: их можно создавать, искать, открывать и удалять.

🖥️

Информация о моделях

Производитель, параметры, размер, русский язык, vision и ориентировочные требования.

Важно знать

Локальный ИИ — это не магия.

Производительность и качество зависят от выбранной модели, её размера, квантования и компьютера пользователя. Минимальные требования являются ориентировочными.

⚡ СкоростьБольшие модели 27B, 30B, 32B и 70B требуют значительно больше RAM и/или VRAM.
🧠 ПамятьПотребление зависит от квантования, длины контекста, GPU, версии Ollama и числа загруженных моделей.
🇷🇺 Русский языкРазмер модели не гарантирует качество русского.
🖼️ VisionНе каждая модель умеет видеть изображения.
🌐 Web SearchИнтернет-поиск требует API-ключ Ollama Web Search и зависит от внешнего сервиса.
🔄 СтабильностьНекоторые модели могут долго загружаться, медленно отвечать или не поддерживать отдельные функции.
💾 Несколько моделейОдновременная работа с несколькими большими моделями может быть некомфортной.
☁️ Не облачная нейросетьLocal AI Studio не является заменой самой мощной облачной модели.
Установка

Просто установите и выберите модель.

В финальной Windows-сборке Ollama предусмотрена как внутренний runtime.

Что входит в установщик

  • Local AI Studio
  • Внутренний Ollama runtime
  • Интерфейс управления моделями и чат
  • Без предустановленных моделей

Почему модели не входят

  • Одна модель может занимать от сотен МБ до десятков ГБ.
  • Пользователь выбирает только нужные модели.
  • Модели скачиваются из самого приложения.
Статус проекта: Local AI Studio — рабочая развивающаяся версия. Возможны мелкие проблемы с отдельными моделями, форматами файлов, мультимодальностью, интернет-поиском и скоростью генерации.
Концепция

Приватность по умолчанию.

В основном локальном режиме цепочка выглядит так: запрос → локальная модель → локальный ответ. OpenAI, ChatGPT и другие облачные модели в приложение не встроены.
